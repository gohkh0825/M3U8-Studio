# Media Go - M3U8 下载与转码工具

这是一个功能强大的 M3U8 视频下载与转码工具，支持硬件加速、实时监控和多种自定义配置。

## 最近更新说明 (Changelog)

### v3.1.3
- **实时网速显示**: 任务列表现在可以显示每个任务的实时下载速度（MB/s, KB/s）。
- **任务搜索功能**: 增加搜索栏，支持根据文件名或 URL 快速过滤任务。
- **批量操作优化**: 改进了全选逻辑，支持更清晰的批量删除和取消确认。

### v3.1.2
- **下载暂停与恢复**: 在下载分片阶段支持随时暂停和继续任务，灵活管理网络资源。
- **智能日志解析**: 重新设计了日志查看器，支持 FFmpeg 日志自动解析，通过图标和颜色区分硬件加速信息、流媒体元数据和编码进度。

### v3.1.1
- **断点续传/跳过下载**: 任务失败或重新开始时，若本地已存在分片，可直接跳过下载直接进入合并/转码阶段。
- **状态感知进度条**: 根据不同阶段（下载中、合并中、转码中、已完成）动态调整进度条颜色，状态一目了然。

### v3.1.0
- **硬件加速优化**: 更新了 VAAPI 硬件加速缩放滤镜（`scale_vaapi`），显著提升了在 Linux 环境下的转码性能和稳定性。
- **全新感知设计**: 优化了界面交互，增强了深色模式下的视觉层次感。

## 核心功能
- **M3U8 多分片并发下载**: 提高下载效率。
- **FFmpeg 强力转码**: 支持 CPU (libx264/libx265) 和 GPU (VAAPI) 编码。
- **硬件加速支持**: 自动检测并利用可用硬件进行视频处理。
- **实时日志监控**: 详细解析 FFmpeg 输出，方便排查问题。

## 使用指南

### 1. 创建下载任务
- **输入链接**: 将 M3U8 视频流地址粘贴至输入框。
- **自定义文件名**: 你可以预先设定保存的文件名，如果不输入将由系统自动生成。
- **配置参数**:
    - **输出格式**: 支持 MP4, MKV, TS (默认为 MP4)。
    - **视频编码**: 
        - `copy`: 直接封装（速度最快，不改变画质）。
        - `libx264/libx265`: CPU 软解（兼容性好）。
        - `h264_vaapi`: **硬件加速**（推荐 Linux 环境使用，速度极快）。
    - **高级选项**: 可设置视频/音频码率，以及是否强制缩放为 1080P。

### 2. 任务管理
- **实时进度**: 进度条会根据当前阶段（下载、合并、转码）变换颜色。
- **暂停/恢复**: 点击任务右侧的 `暂停` 按钮可临时中断下载，再次点击即可继续。
- **日志查看**: 点击 `列表图标` 打开实时日志窗口，系统会自动解析并高亮 FFmpeg 输出的关键信息。
- **搜索过滤**: 使用顶部的搜索栏可以快速找到特定任务。

### 3. 批量操作
- **全选/反选**: 使用列表顶部的复选框可一次性选中当前视图下的所有任务。
- **批量删除/取消**: 选中任务后，顶部会出现批量操作按钮，支持一键清空或停止任务。

### 4. 故障排除
- 如果合并失败，可以尝试点击 `重试`。系统会检测本地已有的分片，**跳过已下载部分**直接尝试重新合并。
- 视频无法播放？尝试将编码设置为 `libx264` 并确保输出格式为 `mp4`。
